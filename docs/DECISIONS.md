# DECISIONS

Standing decisions with rationale. Changed decisions are marked
`SUPERSEDED by Dxxx`, never deleted.

| ID | Decision | Rationale |
|---|---|---|
| D001 | **SUPERSEDED by D015.** Original decision: the only paid item would be a one-month EODHD All-World subscription (~$20) for an "honest" delisted-inclusive backtest. | Vendor documentation later confirmed pre-2018 delisted securities have EOD only, without independently reconstructable split/dividend histories. The snapshot remains useful but is not automatically audit-grade. |
| D002 | PIT rule: a fact is usable at the first session open ≥ its EDGAR `acceptanceDateTime`; the PIT store is as-first-filed (MIN(accepted), insert-only); `prevrpt` and the `frames` API are banned from PIT paths. | Look-ahead and restatement leakage are the two classic backtest poisons; both are structural here, not policy. |
| D003 | v1 universe excludes: OTC, FPIs/ADRs (20-F filers), shells/blank-checks (SIC 6770 now-or-ever, cover-page shell flag), pre-revenue biotech, financials and REITs (from generic scoring). | Each has a mechanical reason (no quarterly data, undefined factors, fraud density) — not a style preference. Carve-out models may come in v2. |
| D004 | "Previous close" = official closing-auction price (NOCP / NYSE auction), never a vendor overnight last-trade. | After-hours prints on thin names corrupt signals; the official close is the only reproducible T-1 reference. |
| D005 | Execution contract: T-1 data → Istanbul-morning decision → LOO orders with ±3-5% collar staged before 09:28 ET → T opening auction fill. Backtest, paper-forward and live use the identical contract, including unfilled-order handling. | Backtest=live parity was the hardest-won MobileInv lesson; MOO in small caps is uncollared gap risk; 09:28 (not 09:30) is the real Nasdaq cutoff. |
| D006 | Raw prices are immutable; adjustments live separately and are recomputable; vendor adjusted closes are never the primary store. | Vendors rewrite adjusted history on every action; reproducibility dies otherwise. (Ported from MobileInv.) |
| D007 | **SUPERSEDED in benchmark naming by D018.** Performance is never reported as a lone number: always net-of-cost, vs the small-cap and broad-market benchmark proxies, with MaxDD/Ulcer/rolling-12m consistency. USD is the base; TRY/gold views are display-only. | Preserves multi-metric discipline while D018 corrects the original index-label overstatement. |
| D008 | **SUPERSEDED by D020.** Original decision: parameters come from a pre-registered grid via "walk-forward" plateau selection and TEST is touched once. | The written design was actually a static holdout, and its run counts/neighborhood topology were not executable. D020 preserves the intent with exact mechanics. |
| D009 | **SUPERSEDED by D024.** Original decision: this repo would produce signals and paper-forward evidence only, with capital execution permanently out of scope. | The paper-forward gate remains mandatory, but the product requirement now includes an explicitly enabled unattended live mode after that gate. |
| D010 | yfinance is banned from all scheduled/automated paths (manual prototyping only). | Operationally broken for unattended use (429 waves, dependency breakage, ToS gray). |
| D011 | A feature that isn't fed (no data/coverage) or doesn't gate is not a feature — it is removed or wired as a hard gate with coverage checks. | Ported from MobileInv (dead CDS/insider/event inputs); red flags here BLOCK selection, not decorate it. |
| D012 | Zero runtime coupling to MobileInv: no shared code imports, separate repos/state/delivery; lessons are ported as specs, code only by copy-with-tests. | Two markets, two data contracts; coupling would let a US change silently break the live BIST system (or vice versa). |
| D013 | All schedules pin to America/New_York; all stored timestamps tz-aware; XNYS exchange calendar is the only source of trading days. | Istanbul has no DST, ET does — the offset shifts twice a year; hand-rolled calendars always get Good Friday or observed-July-4th wrong. |
| D014 | Wrong changes are reverted via revert PR; destructive git (force-push, reset --hard on shared trees) is forbidden. | Ported from MobileInv after a real data-loss incident there. |
| D015 | **SUPERSEDED by D026.** Historical evidence has two modes. Research mode may use the frozen ~$20 EODHD snapshot with `vendor_frozen` adjustment quality where old delisted actions are unavailable; audit mode requires independently reconstructable actions/security identity and a separately approved source/budget. | The evidence-mode distinction remains, but Phase 0.4 found that EODHD's public expiry terms conflict with the assumed one-month-then-retain snapshot. |
| D016 | Entity, tradeable security and ticker are separate identities. Historical joins require an internal `security_id` plus non-overlapping ticker+exchange validity intervals; CIK or ticker alone is forbidden. Alpha Vantage date-specific listing status is a primary universe input after 2010, not merely an audit feed. | CIKs can have multiple share classes and tickers are renamed/recycled. Treating any one identifier as permanent creates false joins and survivorship leakage. |
| D017 | Cash-account rotations default to buys funded only by settled cash available before the auction. Margin or broker acceptance of unsettled proceeds is an explicit account-specific override. | T+1 does not make simultaneous opening-auction sales automatic settled funding under Regulation T; operational assumptions must match the actual broker. |
| D018 | IWM and SPY total-return series are reported as investable benchmark proxies, never as the licensed Russell 2000 TR or S&P 500 TR indices. | ETF fees, tracking and trading mechanics differ from index total returns; precise naming prevents false benchmark claims. |
| D019 | Git stores code, manifests, hashes and small open reference data only. Licensed/multi-GB payloads and mutable DuckDB state live in user-controlled storage with a tested backup; scheduled runtime state stays compact. | Git/LFS/Actions are not a free data lake, and vendor licenses may prohibit redistribution. |
| D020 | Model selection uses the fixed TRAIN/VALIDATION/TEST split and the exact three-stage search in EXPERIMENT_PLAN: 29 OFAT + ≤96 reduced-factorial + ≤60 finalist-neighborhood + ≤5 controls, ≤190 distinct runs. Stage 3 supplies the neighbors used by explicit plateau tolerances; TEST ends 2026-06-30 and is unlocked once. | Corrects arithmetic and makes plateau selection computable without expanding to the 331,776-cell full grid after the large-cap sleeve was added. |
| D021 | Historical price-level rules use contemporaneous raw prices; stops use an as-of split-continuous position basis; return signals use total return. Adjustment factors are anchored to an as-of session and may not incorporate future actions. | Globally split-adjusting history through today's actions can make a future reverse split rewrite old $2 eligibility, market-cap and stop decisions—a subtle form of look-ahead. |
| D022 | After research and deployment, normal production operation is unattended: GitHub Actions is the control plane for incremental ingest, validation, scoring, paper/live order staging, fill reconciliation, ledger update and delivery. No production path may depend on the developer PC being online. Durable runtime state lives in remote object/database storage; duplicate schedules are idempotent and an external heartbeat detects or re-triggers a missed GitHub cron. | GitHub-hosted runners are temporary and scheduled jobs can be delayed or dropped. “Unattended” therefore requires remote state, safe retries, broker idempotency and monitoring outside the scheduler itself—not merely a cron YAML file. Historical research may still use controlled local/batch compute before deployment; that is not a production dependency. |
| D023 | An independent installable PWA is the primary product surface. It reads a versioned derived snapshot from the canonical ledger and exposes selection reasons, portfolio/cash state, performance and data health. It never contains provider secrets, broker credentials or redistributable bulk licensed data; authenticated/private delivery is the default until an explicitly redacted public surface is approved. | The user needs one trustworthy mobile surface, while keeping MobileInv runtime-independent and preventing a convenient UI from becoming a second calculation engine or a data-licensing leak. |
| D024 | Production defaults to automatic paper orders. Live broker submission can be enabled only after the fixed TEST and paper-forward gates, explicit user capital approval, account/funding verification and a kill-switch drill. Once enabled, selection, preflight, order submission and fill reconciliation are unattended; exceptional ambiguity fails closed and alerts rather than requesting routine daily approval. | Profitability is the objective, but automation may not bypass evidence or capital-safety gates. Identical paper/live order contracts preserve realism while removing permanent manual operation. |
| D025 | The $100M–$10B universe remains the core alpha bucket, but companies above $10B are not permanently forbidden. A separately ranked large-cap extension with a hard maximum of {0, 3, 5} portfolio slots is a pre-registered axis; slots are never reserved or forced. | Small/mid caps remain the primary informational-edge hypothesis, while an exceptional cheap, high-quality large company should be able to compete without distorting cross-sectional ranks or dominating the portfolio. |
| D026 | Historical evidence still has `research` and `audit` modes, but either mode requires explicit rights to retain the archive for the full experiment/reproduction period. EODHD remains a research candidate only with written retention permission or a maintained subscription; the published terms checked 2026-07-18 require deletion within one month after expiry, so the former one-month-then-keep plan is prohibited. Audit mode still requires independently reconstructable actions/security identity and a separately approved source/budget. | A reproducible backtest cannot depend on data the license requires us to delete. Cost, field coverage and retention/display rights are separate gates; a cheap API subscription does not silently grant archival or PWA redistribution rights. |
| D027 | The user selected `research` evidence mode. Alpha Vantage is accepted only as the post-2010 dated universe input, not as the price archive or security master. Historical backtesting remains blocked until a retention-permitted price/action archive passes the full sample probe. | The paced personal-key probe matched 24/36 awkward cases but missed all OTC and deliberately pre-2010 cases; two recycled symbols appeared in both active and delisted snapshots. This is useful membership evidence and direct proof that ticker-only identity is unsafe, but it cannot close the price/action archive gate. |
| D028 | `secfsdstools==2.4.3` is pinned as a schema/standardizer reference, but USInv owns the canonical lossless FSDS adapter and Q4 rule contract. Raw SUB/NUM/PRE/TAG fields stay strings; typed NUM values use `Decimal128(28,4)`. | The upstream converter omits TAG and casts NUM to `float64`, and the inspected package does not implement this blueprint's Q4 derivation. Silent field loss or accounting-value rounding is unacceptable in the evidence spine. |
